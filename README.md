# 🎮 Video Game Sales Analysis – Power BI

## 📌 Project Overview

This project focuses on analysing video game sales data using Microsoft Power BI. The main objective is to understand worldwide video game sales, compare regional performance, and identify trends across different genres, gaming consoles, publishers, and critic scores.

The dashboard provides insights into the video game market through interactive visualisations and key performance indicators (KPIs).

## 🎯 Project Objectives

- Analyse worldwide video game sales performance.
- Compare sales across North America, Japan, Europe (PAL), and other regions.
- Identify the best-performing game genres in different regions.
- Analyse gaming console sales by region.
- Identify top-performing publishers.
- Explore the relationship between critic scores and video game sales.
- Examine video game sales trends over release years.
- Identify games with the largest regional sales differences.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualisation.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Measures and calculations.
- **Data Analysis** – Exploring sales patterns and regional performance.

## 🧹 Data Cleaning & Preparation

The dataset was prepared in Power Query before creating the dashboard.

Key data preparation activities included:

- Checked for duplicate records.
- Checked for negative sales values.
- Applied Trim and Clean transformations.
- Identified and reviewed missing values.
- Retained missing critic scores and regional sales values rather than removing those records.
- Removed temporary validation columns after completing the checks.

## 🔍 Key Insights

Some of the findings from the analysis:

- North America recorded the highest regional sales.
- Sports was the leading genre in North America.
- Role-Playing was the leading genre in Japan.
- PS2 was the best-selling gaming console in the dataset.
- Grand Theft Auto V was identified as the best-selling game.
- Activision was the top publisher overall.
- Konami was the top publisher in Japan.
- The average critic score was 7.44.
